# LLM HTML Previewer

Windows 개인용 로컬 데스크톱 앱입니다. LLM이 만든 HTML 또는 Markdown을 왼쪽에 붙여넣고, 오른쪽에서 브라우저처럼 읽기 좋게 미리봅니다.

## Commands

```bash
npm install
npm run dev
npm test
npm run build
npm run dist:win
```

## Scope

- Electron + React + TypeScript + Vite
- CodeMirror editor
- Marked Markdown parser
- DOMPurify sanitizer
- HTML/PDF/PNG/JPG export
- Windows NSIS and portable builds
